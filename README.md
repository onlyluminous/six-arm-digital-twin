# 六自由度机械臂数字孪生仿真平台

毕业设计 | Unity3D + MATLAB/Simscape + Python TCP通信

## 项目介绍

本项目为本科毕业设计，旨在搭建一个六自由度工业机械臂的数字孪生虚拟仿真平台。通过Unity3D实现三维可视化界面，MATLAB/Simscape完成机械臂多体动力学建模与解算，Python负责串口/TCP通信连接虚实两端，实现虚拟模型与真实机械臂的实时同步映射。

## 技术栈

- **可视化前端**：Unity3D (C#)
- - **动力学仿真**：MATLAB / Simscape Multibody
  - - **通信中间件**：Python (socket / pyserial)
    - - **机器人描述**：URDF
      - - **机器人操作系统**：ROS2
        - - **容器化部署**：Docker
         
            ## 主要功能

            1. 六轴机械臂三维建模与运动学可视化
            2. 2. Simscape多体动力学建模与轨迹跟踪
               3. 3. 虚实通信：Python TCP协议实现虚拟端与实物端数据交互
                  4. 4. 虚拟调试：在Unity中预演机械臂作业路径，替代30%以上实物调试工作
                     5. 5. 通信延迟控制在20ms以内
